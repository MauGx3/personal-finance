# Product Context

Why this project exists:

- Provide a personal finance toolkit with data ingestion, visualization, backtesting and tax/reporting utilities.

Problems it solves:

- Aggregates transaction data, computes tax and capital gains, and provides visual analytics and backtesting features.

User experience goals:

- Reliable deployments for both local development and managed PaaS (Leapcell/Portainer), fast feedback loops for developers, and clear documentation for maintainers.
